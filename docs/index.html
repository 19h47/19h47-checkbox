Getting started

This package does not replace native <input type="checkbox">. Prefer a <label> + native checkbox for ordinary forms. Reach for this library when checkboxes must stay in sync through JavaScript orchestration — tri-state parents, conditional groups, shift selection — while keeping HTML as the source of truth.

The plugin doesn't provide any style out of the box. Styles below are for demo purposes only (Bootstrap).

HTML is the source of truth. Set aria-checked, aria-disabled and related attributes in the markup; the library reads them on init() and propagates them to classes and the native input via sync().

Pattern reference: W3C Checkbox Pattern. 

<div role="checkbox" aria-checked="false" tabindex="0">
	<span class="Form__checkbox-box" aria-hidden="true"></span>
	Label text
	<div style="display: none;">
		<input name="option" value="option" type="checkbox" />
	</div>
</div>
import Checkbox from '@19h47/checkbox';

const checkbox = new Checkbox(document.querySelector('[role="checkbox"]'));

checkbox.init();

When to use (expedition roster)

A <label> wrapping each row would work for simple toggles. This roster cannot be solved with labels alone:

  • Recruit all must show aria-checked="mixed" when only some squads are hired — native indeterminate is visual-only and does not drive sibling checkboxes.
  • Quaggoth patrol enables or disables an entire nested group; the parent tri-state reflects how many variants are active.
  • Live counters (squads, units, upkeep vs. budget) must react to every toggle — including nested variants the parent cannot know about in pure HTML.

HTML declares every state; JavaScript wires the relationships via activate(), mix(), and events — see log below.

Methods, getters & events

activate(), deactivate() and mix() write to the HTML. Pass false to skip events (activate / deactivate / mix, plus input and change). Events target the hidden input when present, otherwise the checkbox element.

API playground

Event log

checkbox.activate();           // aria-checked="true"
checkbox.deactivate();         // aria-checked="false"
checkbox.mix();                // aria-checked="mixed"
checkbox.deactivate(false);    // no deactivate event
checkbox.sync();                 // re-apply HTML → classes & input

checkbox.ariaChecked; // "true" | "false" | "mixed"
checkbox.checked;     // boolean
checkbox.disabled;    // boolean

Keyboard support

Key Function
Tab Moves focus to the checkbox (tabindex="0")
Space Toggles state. From mixed or false → true; from true → false

Focus adds the is-focus class (styled above). sync() mirrors aria-disabled to is-disabled and the native input. Disabled checkboxes ignore click and Space.

CheckboxGroup, tri-state & shift selection

CheckboxGroup initializes every [role="checkbox"] inside a container. Hold Shift and click a second checked item to activate all checkboxes in between. The parent « Select All » checkbox uses mix(false) / activate(false) / deactivate(false) to reflect the group without event loops. 

import { CheckboxGroup } from '@19h47/checkbox';

const checkboxgroup = new CheckboxGroup(document.querySelector('.js-city-of-splendors'));

checkboxgroup.init();
// checkboxgroup.checkboxes → Checkbox[]
